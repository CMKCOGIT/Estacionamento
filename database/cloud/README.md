# Banco da nuvem

Modelo de leitura consultado pela API pública: `sites_publicos`,
`disponibilidade_publica`, `tarifas_publicas`, `tickets_publicos` e
`tickets_tokens` (só o hash do token). Sem usuários, caixa ou dados pessoais
além da placa. Aplicado por `npm run db:migrar -w @estacionamento/cloud-api`.
Ver `docs/PWA.md` e `docs/ARQUITETURA.md` §2.7.
